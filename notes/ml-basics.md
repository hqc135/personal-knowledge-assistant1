# 机器学习基础笔记

## 核心概念

### 监督学习 vs 无监督学习
- **监督学习**: 有标签数据，学习输入→输出的映射（分类、回归）
- **无监督学习**: 无标签，发现数据内在结构（聚类、降维）
- **自监督学习**: 从数据自身构造监督信号（BERT、GPT 预训练）

### 过拟合与正则化
- **过拟合**: 模型在训练集上表现好，测试集上差
- **解决方案**: Dropout、L1/L2 正则化、数据增强、早停
- **偏差-方差权衡**: 高偏差=欠拟合，高方差=过拟合

## Embedding 技术

### Word2Vec
- CBOW: 上下文预测中心词
- Skip-gram: 中心词预测上下文
- 训练出的向量能捕获语义关系: king - man + woman ≈ queen

### Transformer 中的 Embedding
- Token Embedding + Position Embedding
- 自注意力机制让每个 token 关注全局上下文
- BERT: 双向编码器，适合理解任务
- GPT: 自回归解码器，适合生成任务

## 向量数据库

### 核心原理
- ANN (Approximate Nearest Neighbor) 近似最近邻搜索
- 常用索引：HNSW (层次导航小世界图)、IVF (倒排文件)
- 距离度量：余弦相似度、欧氏距离、内积

### 常见选型
| 数据库 | 特点 |
|--------|------|
| ChromaDB | 轻量、嵌入式、适合原型 |
| Milvus | 分布式、大规模、生产级 |
| Pinecone | 全托管、零运维 |
| Weaviate | 支持混合搜索 |
