# 面试准备笔记

## 算法与数据结构

### 常见考点
1. **数组与字符串**: 双指针、滑动窗口、前缀和
2. **链表**: 反转、合并、快慢指针检测环
3. **树与图**: DFS/BFS 遍历、最短路径、拓扑排序
4. **动态规划**: 背包问题、最长子序列、区间 DP
5. **排序与搜索**: 快排、归并、二分查找及变体

### 复杂度分析
- 时间复杂度：衡量算法执行时间与输入规模的关系
- 空间复杂度：衡量算法所需额外内存空间
- 常见：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2^n)

## 系统设计面试

### 准备框架
1. **需求澄清**: 明确功能需求和非功能需求（QPS、延迟、数据量）
2. **高层设计**: 画出核心组件和数据流
3. **深入设计**: 选择关键组件展开讨论（数据库选型、缓存策略等）
4. **权衡取舍**: 讨论不同方案的 trade-off
5. **扩展讨论**: 如何扩展到更大规模

### 常见题目
- 设计 URL 短链服务
- 设计新闻推送系统 (News Feed)
- 设计分布式消息队列
- 设计搜索引擎
- 设计限流器 (Rate Limiter)

## 行为面试 (Behavioral)

### STAR 方法
- **S**ituation: 描述背景
- **T**ask: 你的任务/目标
- **A**ction: 你采取了什么行动
- **R**esult: 结果如何，学到了什么

### 常见问题
- 你遇到过最大的技术挑战是什么？
- 描述一次与同事意见不合的经历
- 你如何处理紧急的线上事故？
- 最自豪的一个项目是什么？
